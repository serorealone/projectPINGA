# 🏠 Imobiliária Prime - PWA

Projeto de **Progressive Web App (PWA)** desenvolvido como atividade da **Etec São Mateus**.

Aplicativo web de uma imobiliária, com funcionalidades offline, instalável no celular e com ícone na tela inicial.

---

## 📂 Estrutura do Projeto

```
ProjetoPWA/
├── index.html          # Página principal do site
├── style.css           # Estilos (design responsivo)
├── script.js           # Lógica (filtros, busca, SW, instalação PWA)
├── manifest.json       # Configuração do PWA (nome, ícones, cores)
├── sw.js                # Service Worker (cache + offline)
├── icon-192.png        # Ícone 192x192
├── icon-512.png        # Ícone 512x512
└── README.md           # Este arquivo
```

---

## ✨ Funcionalidades

- 🏠 Catálogo de imóveis (casas, apartamentos, terrenos e comerciais)
- 🔍 Busca por tipo e operação (venda/aluguel)
- 🎛️ Filtros por categoria
- 📱 Design 100% responsivo (mobile, tablet, desktop)
- 📲 Instalável como aplicativo (PWA)
- 📴 Funciona offline (Service Worker com cache)
- 📨 Formulário de contato
- ⬆️ Botão "voltar ao topo"
- 🎨 Banner de instalação do PWA

## 🚀 Como Publicar no GitHub Pages

### 1. Criar repositório no GitHub
- Acesse https://github.com/new
- Nome: `ProjetoPWA`
- Marque como **Público**
- Clique em **Create repository**

### 2. Subir os arquivos
- No repositório, clique em **uploading an existing file**
- Arraste **todos** os arquivos deste projeto
- Clique em **Commit changes**

### 3. Ativar o GitHub Pages
- Vá em **Settings** > **Pages**
- Em **Branch**, selecione `main` e clique em **Save**
- Aguarde 2-5 minutos
- Seu site estará em: `https://SEU_USUARIO.github.io/ProjetoPWA/`

---

## 📲 Gerar o APK (Android)

1. Acesse https://www.pwabuilder.com/
2. Cole o link do seu site publicado no GitHub Pages
3. Clique em **Start**
4. Verifique se todos os itens estão ✅ (manifest, service worker, ícones)
5. Na seção **Android**, clique em **Generate Package**
6. Baixe o arquivo `.apk`
7. Instale no celular e pronto! 🎉
